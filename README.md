# Todo List App

A simple browser-based todo list application built in a single `index.html` file.

## Features

- Add new tasks
- Mark tasks as completed or active
- Edit task descriptions
- Delete tasks
- Filter tasks by `All`, `Active`, and `Completed`
- Clear completed tasks
- Persist tasks in `localStorage` so the list remains after browser refresh

## Usage

1. Open `index.html` in a modern browser.
2. Type a task into the input field and click `Add` or press `Enter`.
3. Use the checkbox to complete or uncomplete tasks.
4. Double-click a task or click the edit icon to modify task text.
5. Use filter buttons to switch between `All`, `Active`, and `Completed` tasks.
6. Click `Clear completed` to remove all finished tasks.

## Notes

- No build tools or dependencies are required.
- The app runs entirely in the browser.
- Task data is stored locally in the browser via `localStorage`.

## File

- `index.html` — main todo app file containing HTML, CSS, and JavaScript.
